## 팀 빌딩

먼저 체크인한 참가자의 GitHub 핸들을 등록해야 합니다. 핸들 등록 양식에서 GitHub Copilot 라이선스가 활성화된 계정인지 확인하고, 이메일이 아닌 GitHub 핸들을 입력해 주세요.

참가 핸들 등록 👉 [이슈 양식 선택](https://hackersground.kr/hackathons/cheongdo/issues)

결과를 제출하기 전에 팀을 등록해야 합니다. 팀 리더가 직접 팀 등록 양식을 제출하며, 팀 등록 마감은 따로 없습니다. 팀원 수 제한은 현재 양식에서 확인되지 않아 별도 안내합니다. 같은 리더가 다시 제출하면 새 팀 대신 기존 팀 정보가 업데이트되고, 팀 이름은 대소문자를 구분하지 않고 고유해야 합니다.

팀 등록하기 👉 [이슈 양식 선택](https://hackersground.kr/hackathons/cheongdo/issues)

## 앱 제출

팀 등록 후 아래 링크에서 결과 제출 양식을 작성해 주세요. 제출 마감은 **2026년 11월 5일 16시 30분(한국 시각)**이며, 팀당 최대 2회 제출할 수 있습니다. 가장 나중에 제출한 이슈를 기준으로 평가합니다.

제출 전에 다음 사항을 확인해 주세요.

- 팀 리더 본인의 공개 GitHub 저장소를 사용하고, 저장소 루트에 `PRD.md`와 `TRD.md`를 둡니다.
- 제출할 커밋 해시와 앱 배포 URL을 입력합니다.
- 앱은 Azure 클라우드에 배포해야 하며, Azure 기본 도메인 URL을 사용합니다.
- 심사 에이전트가 별도 계정이나 자격 증명 없이 앱의 핵심 기능을 사용할 수 있어야 합니다. 제출 이슈에 비밀번호나 토큰을 입력하지 마세요.
- 심사는 AI 에이전트가 저장소의 `PRD.md`, `TRD.md`와 앱의 실제 동작을 바탕으로 진행합니다. `README.md`는 보조 자료로 사용됩니다.

앱 제출하기 👉 [https://hackersground.kr/hackathons/cheongdo/issues](https://hackersground.kr/hackathons/cheongdo/issues)
