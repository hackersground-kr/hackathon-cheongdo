## Team Formation

First, register the GitHub handles of checked-in participants. In the handle registration form, confirm that the account has an active GitHub Copilot license. Enter a GitHub handle, not an email address.

Register a participant handle 👉 [Choose an issue form](https://hackersground.kr/hackathons/cheongdo/issues)

Register your team before submitting a project. The team leader must submit the team registration form. There is no separate deadline for team registration. The current form does not specify a team size limit; this will be announced separately. If the same leader submits the form again, the existing team will be updated rather than a new team being created. Team names must be unique, regardless of capitalization.

Register a team 👉 [Choose an issue form](https://hackersground.kr/hackathons/cheongdo/issues)

## Project Submission

After registering your team, submit your project using the form at the link below. The submission deadline is **November 5, 2026, at 4:30 PM Korea Standard Time (KST)**. Each team may submit up to two times. The most recent submission issue will be used for evaluation.

Before submitting, make sure that:

- You use a public GitHub repository owned by the team leader, with `PRD.md` and `TRD.md` in the repository root.
- You provide the commit hash being submitted and the deployed app URL.
- The app is deployed to Azure and uses an Azure default domain.
- The judging agent can use the app's core features without an account or credentials. Do not include passwords or tokens in the submission issue.
- The AI agent evaluates the repository's `PRD.md`, `TRD.md`, and the app's actual behavior. `README.md` is used as supplemental material.

Submit your project 👉 [Choose an issue form](https://hackersground.kr/hackathons/cheongdo/issues)
